## Technische Projektanalyse (PDF)

| Datei | Beschreibung |
|-------|----------------|
| `Technische_Projektanalyse_NoitaClone.md` | **Vollständige Analyse** (15 Kapitel, Mermaid, Anhänge) |
| `Technische_Projektanalyse_NoitaClone.pdf` | PDF-Export (via Skript oder Drucken aus MD) |

### PDF neu erzeugen

Mit Node.js (z. B. Cursor-Node):

```powershell
cd docs
node generate_analysis_pdf.js
```

### Alternative: hochwertigeres PDF

1. `Technische_Projektanalyse_NoitaClone.md` in VS Code/Cursor öffnen  
2. Markdown Preview → Rechtsklick → **Drucken** / **Print** → „Als PDF speichern“

Oder die `.md` in GitHub/GitLab anzeigen und als PDF exportieren.
